# 関数一覧（def で定義している関数）

アプリ本体のコード（`app.py`・`search/`・`register/`・`initial_load/`）にある、`def` で定義した関数 165 個の一覧です。テスト用のコード（`_test/`）は含みません。

## 見方

- **大区分**：どの機能のための関数か。複数の機能から使う関数は、一番主な機能に1行だけ入れています（共通で使うものは「⑦ 共通部品」）
- **小区分**：処理の段階。準備（読み込み）→ 前処理 → 検索・計算 → 順位づけ → AI生成 → チェック → 保存 → 設定 → 表示
- **外部**：OpenAI（AIの呼び出し）／Supabase（DBの読み書き）／なし
- **補助**：`_` で始まる関数、関数の中の関数、クラスのメソッド
- 「行」は、そのファイルの中で `def` が始まる行番号です
